## UE widget binding checklist

Before marking a slot widget "done":

- [ ] Every `BindWidget` / `BindWidgetOptional` has **`BlueprintReadOnly`**
- [ ] C++ member type matches UMG widget class (CommonUI types included)
- [ ] Designer widget **Name** == C++ property name (e.g. `Text_Timer`)
- [ ] BP subclass **Compile** succeeds; `Get Text_Timer` appears in graph
- [ ] C++ module recompiled after header change (not Live Coding only)

---

## UE compile checklist

- [ ] `#include` full type in `.cpp` when calling methods on pointer
- [ ] `TSubclassOf<T>` / `BindWidget` need full type in header
- [ ] GF primary assets: `AssetBaseClass=/Script/Engine.PrimaryDataAsset` in `DefaultGame.ini`
- [ ] Native tags (`FNativeGameplayTag`): use `.GetTag().IsValid()`, not `.IsValid()`
- [ ] Helpers that pass `this` as world context must be non-static
- [ ] Run the compile gate after C++ edits; preserve unsaved work, close the editor gracefully when needed, fix build errors, restart, and verify relevant PIE behavior

## When to extend this skill

Append a new **BF-00N** row when:

- A bug took >1 attempt to diagnose
- The same mistake could recur in another file/module
- A tooling/MCP script assumed wrong API (e.g. wrong MCP param names)

Keep rows concise. Link to file paths, not long prose.

### BF-044 - Replicated active effect has no definition

Infinite passive-gold income used a transient server-only UGameplayEffect definition. Use a native class or asset for duration/infinite effects and supply runtime magnitudes on each spec through SetByCaller. Verify remote-client definition resolution, one income tick per second, round-end removal, and no stacking across rounds. See Plugins/GameFeatures/BreakawayCore/Docs/Passive_Gold_Replication_Verification.md. Source fix applied; compile and PIE pending.


### BF-045 - Rejected buildable submission leaves placement active

UserConfirmed WaitTargetData ends after submitted data even when the ability rejects it. End the ability on every terminal submission path, validate target-data script type before downcasting, distinguish an intentionally absent remote-server target actor from a real spawn failure, and guard synchronous cached-data completion during task setup. See Plugins/GameFeatures/BreakawayCore/Docs/Buildable_Targeting_Replication_Verification.md. Source fix applied; compile and PIE pending.


### BF-046 - UE 5.8 JSON shared keys fail FString conversion

FJsonObject Values keys are shared strings in this engine version; implicit FString initialization and forwarding directly to FJsonValueString fail. Explicitly construct FString from the key character data when an owned string is required. Fixed remaining FoliageHandlers and LevelHandlers call sites. LyraEditor Win64 Development compile passed September 5, 2026.

### BF-047 - Build wrapper waits after UBT has exited

Start-Process -Wait can retain its process-tree wait under the agent host after all build children exit. Launch with -PassThru and wait on the returned Process with WaitForExit, then Refresh and inspect ExitCode. Confirm the actual process tree before stopping a stalled wrapper; never infer termination from an observation timeout or start duplicate builds. Retry compile gate passed September 5, 2026.


### BF-048 - LAN hosts and browser searches use different modes

Custom matchmaking defaulted to Offline while the browser factory created Online searches. Add a shared configurable request default, set the slice to LAN, disable lobby/presence flags for LAN, and align quick-play search with its host request. Verify generated request modes and test discovery/join in separate processes; successful compilation is insufficient.


### BF-049 - Timed-out bridge callback crashes editor later

GameThreadExecutor captured caller stack references and returned its event to the pool before a delayed ticker finished. Share completion state with the ticker, capture handler and parameters by value, return the event only when both owners release it, and skip queued work after timeout. A running handler cannot be rolled back by timeout. Regression: ProjectB.MCP.QueuedTimeoutLifetime. On September 7, an uncommitted change had removed this already-committed protection; a modal timeout reproduced the crash. Restoring the committed implementation and rerunning the existing automation test passed. Check worktree changes as well as history before trusting a previous bridge fix.

### BF-050 - Python probe retains old PIE world through travel

Persistent Python globals can keep a World or PlayerController alive and trigger old-world GC ensures during hard travel. Use function-scoped runtime probes and release all world/actor wrappers before the deferred travel tick. Do not report probe-induced GC warnings as gameplay defects without tracing their reference chain.
