# CLI Status Line

Identify the CLI and its supported status-line configuration through current host documentation. Use its actual schema and resolved paths; do not apply the legacy Cursor JSON schema to Codex.

Use [the legacy Cursor reference](references/legacy-cursor-statusline.md) only for an explicitly identified Cursor-compatible host after verifying its packages, paths, and tool schema. Do not load it for current Codex tasks.
