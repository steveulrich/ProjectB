# Interactive Canvas

For an existing canvas, use its actual runtime and location. For a new requested interactive artifact, use the active host's visualization capability and documented workspace. The legacy cursor/canvas SDK and macOS directory are not defaults for the current Codex app.

Use [the legacy Cursor reference](references/legacy-cursor-canvas.md) only for an explicitly identified Cursor-compatible host after verifying its packages, paths, and tool schema. Do not load it for current Codex tasks.
